# Vibes

A music player for [Navidrome](https://www.navidrome.org) servers, for
Android and iPhone. This page only has the app to download.

**You need an account on a Navidrome server** — ask whoever runs it for a
username and password, and the server's address. You'll type these in when
you first open Vibes.

---

## Android

### The simple way

1. On your phone, open the
   [latest release](https://github.com/LLama422/Vibes-releases/releases/latest)
   and tap **`Vibes-build-….apk`** under *Assets* to download it.
2. Open the downloaded file. If your phone asks, allow your browser (or
   Files app) to **install unknown apps**, then go back and tap
   **Install**.
3. Open Vibes and sign in.

To update, download the newest file the same way and install it over the
old one — your settings and downloads stay.

### Automatic updates (Obtainium)

[Obtainium](https://obtainium.imranr.dev) installs app updates straight
from download pages like this one.

1. Install Obtainium from its website.
2. In Obtainium tap **Add app**, paste
   `https://github.com/LLama422/Vibes-releases` and tap **Add**, then
   **Install**.
3. Obtainium checks for new builds and offers to update Vibes.

## iPhone

Vibes isn't on the App Store. You install it with **SideStore** (or
**AltStore**), which put it on your phone using your own free Apple ID.
Setting it up takes about 20–30 minutes, once.

- Apps installed this way need refreshing every **7 days**. SideStore
  (and AltStore, while its helper runs on your computer) does this for you
  in the background — open it now and then to make sure.
- A free Apple ID can have **3** apps installed this way at a time
  (SideStore/AltStore counts as one).

### Steps

1. Install **SideStore** by following its guide:
   <https://docs.sidestore.io/docs/installation/prerequisites>.
   (Or AltStore: <https://faq.altstore.io>.) You'll need a computer for
   this part.
2. In SideStore, go to **Sources**, tap **+**, and add:

   ```
   https://raw.githubusercontent.com/LLama422/Vibes-releases/main/altstore.json
   ```

3. Find **Vibes** in the source and tap **Free** / **Get** to install it.
4. Open Vibes and sign in. Allow *local network* when asked — it's needed
   to reach the server and to play on speakers and TVs.

Updates show in SideStore under **My Apps**.

Prefer to install by hand? Each iPhone release on the
[Releases page](https://github.com/LLama422/Vibes-releases/releases) has
a `Vibes.ipa` file you can open with SideStore or AltStore.
